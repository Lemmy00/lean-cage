# Actual caller string checks

For [§AR-m4-controller.strings](../../docs/architecture/AR-m4-controller.md#strings-actual-caller-string-checks), this package connects the actual mode, export,
digest-option and executable validation statements to their exact byte predicates.
It preserves the complete helper and all earlier checkpoint propositions.

The source certificates cover every actual transition before the stated boundary,
including arbitrary strcmp magnitudes, waiting and terminal process loss.
Success reaches the actual continuation; rejection reaches the actual result_of
call. A boundary split prevents extending memory claims into later source code.
The executable check composes with argument accumulation and policy bounds.

Run `python3 m4/validation/check.py` after the original, bridge, controller,
plan, main, policy, arguments and digest gates. `--collect` creates ignored
candidate evidence and never refreshes reviewed expectations. The gate checks
complete theorem types and foundations, exact export and artifact identities,
negative controls and independent kernel replay. See the proposition review in
`docs/reviews/M4-validation.md`.

These are kernel-constructed source executions, not VM measurements. Whole-main
entry, physical argument provenance, preceding pointer stores, parent identity,
report publication, Linux effects, libc implementation, translation faithfulness
and hardware channels remain open. Full M4 and the whole controller are incomplete.
