# Historical caller module identities

These fifteen exact sources supply historical module names imported by the
caller proofs and printed in their reviewed theorem types. The initial caller
replay found them in the ignored local build directory. The decoder package
makes that entire dependency closure maintained and audited under
[§AR-m4-effects.gate](../../../docs/architecture/AR-m4-effects.md#gate-additive-evidence-and-completion-boundary) and [§AR-m4-decoder.evidence](../../../docs/architecture/AR-m4-decoder.md#evidence-full-source-evidence-and-inhabited-inputs).

The `Draft` suffix is retained only to preserve those existing module identities,
statements and compiled artifacts. These files contain complete checked proofs.
New source modules use their maintained names. The gate inventories and checks
all declarations here, copies these sources before dependent compilation, and
rejects every undeclared project import. No proof may depend on an incidental
file in the build cache.
