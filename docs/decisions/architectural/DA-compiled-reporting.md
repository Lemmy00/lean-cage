# DA-compiled-reporting: Instantiate and consume the reporting compiler proof

Under [§AR-compiled-reporting.connection](../../architecture/AR-compiled-reporting.md#connection-carry-the-reporting-argument-across-verified-compilation) and [§FS-workspace.results](../../functional-spec/FS-workspace.md#results-entry-cancellation-and-bounded-transport), start from
Clight's temporary-parameter semantics and compose the pinned compiler's eight
required pass proofs. The existing whole C compiler theorem starts at a different
semantics boundary. Make the untrusted allocation candidate an ordinary argument
to the complete original allocation validator and proof. Check the current
helper plus the explicit logical runtime unit through concrete compilation
equations; apply those equations to the reporting consumer.

Keep all fixed compiler choices and computation adapters in a derived local
profile. Select ELF x86-64 calling conventions in the two ABI clients. Use a
proved executable iterator equality and transparent solver interfaces to check
the actual validator without rebuilding the unchanged source foundation. The
original pins, compiler tree, proof snapshots and GCC deployment remain intact.

An unrooted private errno address cannot satisfy the stock compiler's external
memory-injection interface. Provide a preserved public root in the logical
per-thread runtime view and recheck the unchanged helper bodies in that global
environment. This supplies an interface for a runtime implementation, not a
replacement of physical libc TLS with a normal global. The runtime, matched
caller state, partial-call loss and deployed binary chain remain required
producers. The new result is conditional compiler-model evidence and closes no
original ledger entry.
